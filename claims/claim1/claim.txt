Function Retrieval under Compiler Inlining

This claim demonstrates that PinPoint improves the retrieval of vulnerable code
in target binaries over the binary code similarity detection (BCSD) backbone it
is built on, and reproduces the type-wise Top-K accuracy and MRR of Table III.

The evaluation runs the packaged subset twice: once restricted to Stage 1,
which is whole-function comparison and therefore the backbone evaluated
standalone, and once with PinPoint's full three-stage cascade. Both are scored
with topk_table.py, the same analysis code that produced the paper's table, so
the two configurations are measured on identical binaries. Results are reported
per inlining type (Types I-IV, defined in Section III) and overall.

The gain concentrates on Type II, where the compiler inlined the vulnerable
function into a non-vulnerable host and it no longer survives as a routine with
a boundary a function-granularity model can match against.

The BCSD backbone is BinShot, from: S. Ahn, S. Ahn, H. Koo, and Y. Paek,
"Practical binary code similarity detection with BERT-based transferable
similarity learning," in Proceedings of the 38th Annual Computer Security
Applications Conference (ACSAC '22), 2022.
